# ProjMatLab

## Requirements

* MATLAB (or GNU Octave, if compatible)
* Git

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/wisewirus/ProjMatLab.git
```

### 2. Navigate to the project directory

```bash
cd ProjMatLab
```

### 3. Open the project in MATLAB

Launch MATLAB and open the `ProjMatLab` folder.

### 4. Run the project

Run the main script (for example, `proj.m`) from the MATLAB Editor or the Command Window.

```matlab
proj
```
